# Lime Flyer

A sub-250 g RC flying wing: 3D-printed mount and foam-sheet airframe, 2S power, flown from the FS-i6.

The project started as a larger tilt-tri VTOL and was scaled down to a simple micro plane that can be built and flown this winter. The old design is in the git history (commit `1ddb056` has the final tilt-tri files under `archive/tilt-tri/`).

- Parts list and weight budget: `docs/BOM.md`
- Design guide with live calculators: open `docs/design-guide.html` in a browser
