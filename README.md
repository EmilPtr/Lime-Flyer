# Citrus micro plane

A sub-250 g RC flying wing: 3D-printed mount and foam-sheet airframe, 2S power, flown from the FS-i6.

Project scope changed from a 870 g tilt-tri VTOL (now in `archive/tilt-tri/`, on hold) to a simple micro plane that can be built and flown this winter.

- Parts list and weight budget: `docs/BOM.md`
- Old tilt-tri design, geometry script and BOM: `archive/tilt-tri/`
